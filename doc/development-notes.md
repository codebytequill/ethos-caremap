# Development Notes

## Project Background

Ethos CareMap began as a response to real-world caregiving challenges experienced while navigating hospitals, rehabilitation facilities, medical records requests, care coordination, advocacy efforts, and end-of-life planning.

The project was created to explore how thoughtful software design could help families remain organized during some of the most stressful and emotionally overwhelming moments of their lives.

---

## AI-Assisted Development

Ethos CareMap was developed using an AI-assisted workflow that included OpenAI Codex, iterative prompt engineering, manual testing, product documentation, and human review.

Rather than beginning with code, development began with a problem statement and a clearly defined user need.

AI-assisted development tools were used to accelerate prototyping while all product direction, feature prioritization, testing, and documentation decisions remained human-led.

---

## Initial Build Prompt

Version 1 focused on:

* Timeline Builder
* Contacts Directory
* Records Tracker
* Questions and Concerns Log
* Preservation Actions Tracker
* Case Dashboard

The goal was to create a compassionate, caregiver-friendly MVP that prioritized organization, clarity, and ease of use.

---

## Early Testing

Initial testing included manual user validation of:

* Timeline entry workflows
* Data persistence behavior
* User interface navigation
* Input validation

During testing, a date-handling issue was identified involving historical year values entered into the Timeline Builder.

The issue was documented and submitted for correction as part of the quality assurance process.

---

## Lessons Learned

Key observations from the first build:

* Documentation is as important as functionality.
* Real-world caregiving workflows differ significantly from traditional project-management tools.
* Privacy considerations must be incorporated from the earliest stages of development.
* AI-assisted development dramatically accelerates prototyping but still requires thoughtful testing and human review.
